# Command-Line-Shell
## U_Shell is a command line shell that basically runs in a text window and causes respective action when recieves a command.
### Below are some of the recognized commands by J_Shell.
#### 🔑 U_pwd             The Current Working Directory
#### 🔑 U_ls              List of Sub Directories in the Current directory
#### 🔑 U_cd              To Change the Current Working Directory
#### 🔑 U_lstype          To display the list of items of sepcific type
#### 🔑 U_memory          To get the Total, Used and Avaiable Memory of the System
#### 🔑 U_mkdir           To Make a new Directory
#### 🔑 U_rmdir           To Remove a particular Directory
#### 🔑 U_rename          To Rename a directory
#### 🔑 U_mkfile          To Make a New File (txt, cpp, py, xls, pptx, pdf etcccc.)
#### 🔑 U_rmfile          To Delete a File
#### 🔑 U_copy            To copy contents of a file from one location to other
#### 🔑 U_exist           To check if a particular file or folder Exits
#### 🔑 U_echo            To print the Text on the terminal as it is
#### 🔑 U_read            To Read each and every word from a file
#### 🔑 U_sort            To sort the content of the file in Lexicographical order
#### 🔑 U_time            To Display current Day, Date and Time
#### 🔑 U_history         To display the history of the commands of the current session.
#### 🔑 U_clear           To Clear the Terminal
#### 🔑 U_help            To display the list of all the present commands
